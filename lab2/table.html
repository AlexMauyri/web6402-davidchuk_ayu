Сравнительный анализ архитектуры

Цель сравнения — показать различия между однопользовательской хобби-системой прямого доступа и многопользовательскими защищёнными ОС общего назначения. TempleOS нельзя рассматривать как замену Linux или Windows, но можно оценить как сольный инженерный манифест.

Сравнение по ключевым параметрам

Параметр TempleOS Linux Windows
Кольца привилегий Только Ring 0 (все привилегии) Ring 0 (ядро) + Ring 3 (пользователь) Ring 0 (ядро) + Ring 3 (пользователь)
Адресное пространство Плоское (identity mapping, без MMU) Виртуальное (MMU + swap) Виртуальное (MMU + pagefile)
Сетевой стек Отсутствует (изоляция) Полный (TCP/IPv4/IPv6, Berkeley) Полный (TCP/IPv4/IPv6, Winsock)
Графический режим 640×480, 16 фиксированных цветов Динамический (Wayland/X11, TrueColor) Динамический (DWM/DirectX, TrueColor)
Язык кодовой базы HolyC (100% ядра и утилит) C, ассемблер, Rust C, C++, C#
Количество разработчиков 1 человек (Терри Дэвис) Тысячи (сообщество, вендоры) Тысячи (Microsoft)
Лицензия Public Domain GNU GPL v2 Проприетарная

Выводы о назначении систем

TempleOS — не замена Windows или Linux. Это монументальный сольный инженерный манифест в духе ретро-компьютеров. Linux и Windows — массовые многопользовательские системы с защитой памяти, сетью и тысячами драйверов. Сравнение показывает три разных подхода к тому, какой вообще может быть операционная система.

В то время как коммерческие и индустриальные решения развиваются по пути изоляции, абстракций и строгой безопасности, архитектура Терри Дэвиса демонстрирует радикальную альтернативу: компьютер как прозрачный монолитный инструмент для одного исследователя.
