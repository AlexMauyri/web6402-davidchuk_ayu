# Лабораторная работа №2

**Тема:** Основы HTML и CSS. Многостраничный статический сайт.

**Цель:** изучить основы HTML и CSS, разработать многостраничный сайт и загрузить проект в репозиторий.

**Тема сайта:** «Терри Дэвис и TempleOS» — операционная система, написанная одним человеком с нуля.

**Структура:**
lab2/
├── index.html # главная — биография и философия проекта
├── features.html # технические особенности
├── table.html # сравнение TempleOS с Linux и Windows
├── css/
│   ├──style.css # единый файл стилей
└── images/
    ├── favicon.svg # иконка сайта и логотип в шапке
    ├── terry-davis.jpg # портрет
    ├── templeos-logo.png # логотип с мечом и весами
    ├── holyc-code.png # фрагмент кода на HolyC
    └── templeos-screen.jpg # скриншот интерфейса

**Использованные технологии:**
- HTML5 — семантическая разметка.
- CSS3 — оформление, переменные, flexbox, псевдоклассы.
